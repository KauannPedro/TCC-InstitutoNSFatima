## 📌 Sobre o Projeto

O **EcoWoods** é uma aplicação web de e-commerce desenvolvida com o objetivo de conectar consumidores a produtos ecológicos e sustentáveis. 

O projeto foi construído do zero focando em uma arquitetura moderna com **React.js** e **TypeScript** no Front-end e **Node.js** no Back-end, oferecendo uma experiência de compra rápida, intuitiva e responsiva.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React.js, TypeScript, HTML5, CSS3 (Modular/Styled)
- **Back-end:** Node.js, Express.js
- **Linguagens:** JavaScript (ES6+), TypeScript
- **Ferramentas de Versionamento:** Git & GitHub

---

## 🚀 Funcionalidades da Aplicação

- [x] **Catálogo de Produtos:** Exibição dinâmica de produtos sustentáveis.
- [x] **Carrinho de Compras:** Adição, remoção e cálculo em tempo real de produtos.
- [x] **Design Responsivo:** Interface adaptada para dispositivos móveis e desktop.
- [x] **Filtros e Buscas:** Pesquisa otimizada de itens por categoria.
